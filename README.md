# Арена Древних — HTML5-игра для Яндекс Игр

Аренный экшен в сеттинге MOBA: герой отбивает бесконечные волны врагов,
между волнами качает умения и закупается в лавке. Каждая пятая волна — босс.

## Архитектура

Ноль внешних зависимостей, ноль картинок и звуковых файлов и никакой сборки:
графика рисуется процедурно на canvas, звук синтезируется через WebAudio,
файлы подключаются обычными `<script>`. Игра открывается двойным кликом по
`index.html` и работает на всех браузерах из п. 1.20 требований.

### Слои

Зависимости идут строго сверху вниз. Слой может обращаться к тем, что ниже,
и никогда — к тем, что выше.

```
ui        экраны, HUD, ввод пользователя
render    отрисовка кадра
game      состояние мира, боевая логика, ИИ
content   данные: герои, умения, предметы, карты
platform  SDK Яндекс Игр, сейвы, локализация
core      математика, звук, ввод, неймспейс
```

Единственное правило, которое держит всё это без сборщика:

> **На верхнем уровне файла — только объявления.**
> К соседним модулям обращаться через `AA.<Слой>.<модуль>` внутри функций,
> то есть уже после того, как всё загрузилось.

Порядок подключения задан один раз — в манифесте внизу `index.html`.
Проверить, что всё на месте: `AA.list()` в консоли.

### Как добавить

**Новое умение** — дописать объект в подходящий файл `content/skills/`
и указать его id в `skills` героя. Умения видят только `AA.Game.api`,
поэтому дать им новую возможность = добавить метод в `game/api.js`.

**Нового героя** — запись в `content/heroes.js`, четыре умения,
карта в `content/maps.js`, профиль анимации в `render/anim.js`
и набор внешности в `KITS` (`render/shapes.js`).

**Новый тип врага** — запись в `content/enemies.js`, ветка поведения
в `game/ai.js` (если нужна особая роль) и силуэт в `render/shapes.js`.

**Умение боссу** — функция в объекте `BOSS` (`game/ai.js`) и строка
`{ id, cd }` в его `abilities` в `content/enemies.js`.

**Новую руну** — запись в `content/runes.js`, всё остальное подхватится само.

**Талант** — запись в дерево героя в `content/talents.js`. Если он меняет
характеристики, достаточно поля `stat`; если перезарядку — поля `cd`;
если поведение умения — проверка `api.talent(u, 'id')` в самом умении.

**Облик** — запись в `content/skins.js`: палитра и, для имморталки, тип эффекта
из `skinFx` в `render/units.js`.

**Главу истории** — запись в `content/story.js`.

**Новый экран** — файл в `js/ui/`, разметка в `index.html`,
регистрация в списке экранов `ui/screens.js`.

Распакованный размер около 190 КБ при лимите 100 МБ.

## Система характеристик

Упрощённая дотовская: три атрибута, у каждого героя есть главный.

| Атрибут | Что даёт |
|---|---|
| Сила | +20 здоровья, +0.1 восстановления здоровья за очко |
| Ловкость | +0.16 брони, +1% скорости атаки за очко |
| Интеллект | +12 маны, +0.055 восстановления маны, +0.75 силы заклинаний за очко |
| Главный | дополнительно +1 к урону атаки за очко |

Атрибуты растут с уровнем героя внутри забега и с постоянным уровнем,
который покупается за души между забегами. Все коэффициенты — в `ATTR` в начале `js/data.js`.

Физический урон режется бронёй по формуле `1 − 0.06·броня / (1 + 0.06·|броня|)`,
магический — процентом сопротивления магии.

## Мир и камера

Мир **вдвое больше экрана** — от 1700×1250 до 2600×1900 в зависимости от
устройства. Камера едет за героем с упреждением по направлению движения и
мягко догоняет его, на краях мира упирается. В правом верхнем углу —
**миникарта**: рельеф, враги, боссы, руны, рамка текущего кадра и герой.

Волны спавнятся не по краям мира, а кольцом вокруг героя сразу за кромкой
кадра: враги приходят отовсюду, но не идут через полкарты. Руны появляются
в 320–900 от героя, чтобы за ними имело смысл бежать.

Фон карты запекается в размер мира один раз, за кадр рисуется только видимый
кусок; юниты и объекты вне кадра пропускаются при отрисовке.

## Иконки

У каждого предмета и умения **своя иконка**, нарисованная кодом. Библиотека
из тридцати с лишним базовых глифов — меч, топор, лук, щит, сапог, сфера,
пламя, снежинка, молния, лист, череп, книга, песочные часы и так далее —
плюс окраска под цвет умения или редкость предмета и рамка. Файлов на диске
по-прежнему ноль.

Новому предмету достаточно строки в `GLYPH_OF` (`js/render/icons.js`),
рисовать заново ничего не нужно.

## Арены

У каждого героя своя карта со своей палитрой, освещением и ландшафтом —
Скотобойня, Лесная опушка, Ледяной фьорд, Замёрзшее озеро, Разрушенный замок,
Ночные катакомбы, Священная роща, Парящие руины, Вулканический кратер, Каменоломня.

Объекты ландшафта не декоративные. **Блокируют движение:** скалы, колонны,
деревья, руины, кристаллы, жаровни, обелиски со светящимися рунами и грибы.
За ними прячутся от стрелков. **Влияют на бой:** лава и шипы наносят урон,
лёд и паутина замедляют. **Только для вида:** кости, трава, кусты, лужи, трещины.

У каждой арены своя взвесь в воздухе — снег на фьорде и озере, пепел на
скотобойне и в кратере, листья в лесу, пыль в замке и каменоломне,
светлячки в роще и катакомбах, осколки пустоты в парящих руинах.

Раскладка генерируется по фиксированному зерну, поэтому карта героя всегда
узнаваема. Автобой умеет обходить препятствия.

Карты — `MAPS` в `js/content/maps.js`, свойства типов — `PROP` в
`js/game/terrain.js`, отрисовка — `js/render/props.js`, погода — `WEATHER`
в `js/render/fx.js`.

## Учебный полигон

Отдельный режим из главного меню:

- герой сразу 25 уровня, все умения максимального уровня;
- бесконечное золото, лавка открыта в любой момент;
- три манекена с большим запасом здоровья, которые возрождаются после смерти;
- кнопки «+ ВРАГ» и «+ БОСС» — вызвать любого противника для проверки сборки;
- счётчик урона в секунду за последние 5 секунд;
- смерть не завершает сессию, герой просто возрождается.

## Герои (10)

У всех героев **три активных умения и одно пассивное**. Активные качаются до 4 уровней,
кап уровня растёт вместе с уровнем героя. Предельный уровень — **50**; когда умения
упираются в потолок, очки вкладываются в главный атрибут по +3 за очко.

**Уровень даётся за волну, а не за опыт.** Обычная волна — один уровень,
боссовая — сразу два. К 45-й волне герой упирается в потолок, а таланты падают
ровно на 10, 20, 30, 40 и 50 уровнях. Купить уровень заранее нельзя: все герои
стартуют с первого, души тратятся только на новых бойцов и облики.

### Демон Клинков

Керри-иллюзионист: дерётся чужими руками и расцветает к поздним волнам.
Самый высокий прирост ловкости в ростере (4.4 за уровень) при слабом старте.

- **Отражение** — помечает врага: замедление и его собственная **неуязвимая**
  копия, которая бьёт только его самого его же уроном. Исчезает вместе с оригиналом.
- **Раскол** — две своих копии на 24 секунды: бьют долей урона, получают втрое
  больше, снимают с героя все дебаффы при создании.
- **Метаморфоза** — превращает героя **и все его копии** в дальнобойную форму:
  +урон и дальность атаки с 70 до 530.
- **Разрыв** (пассивное) — копии бьют сильнее, а когда здоровье падает ниже 28%,
  герой автоматически меняется процентом здоровья с ближайшим врагом. Раз в 45 секунд.

Копии — полноценные юниты на стороне игрока: враги переключаются на ближайшую
цель, поэтому иллюзии реально оттягивают урон, а не стоят декорацией.
Система копий общая (`illusion` в `js/game/factory.js`), так что её можно
переиспользовать для других героев и предметов.

### Секира → Берсерк

Старый герой был пассивным: провокация плюс вращение — стоишь и ждёшь.
Берсерк построен вокруг риска: пассивка **Кровавая ярость** даёт до +105% урона и
скорости атаки тем больше, чем меньше осталось здоровья, **Безумие** добавляет
скорость атаки и вампиризм ценой 35% брони, а **Прыжок** и **Раскол** заставляют
лезть в самую гущу. Играть надо на низком здоровье — это совсем другой ритм боя.

### Аркан: 10 связок

Вместо обычных умений у Аркана три стихии на клавишах <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd>:
**Пламя**, **Лёд**, **Шторм**. Последние три нажатия складываются в связку,
клавиша <kbd>4</kbd> (или <kbd>F</kbd>) вызывает заклинание этой связки.
Сила заклинания = сумма уровней трёх использованных стихий (от 3 до 12).

| Связка | Заклинание |
|---|---|
| Пламя ×3 | Испепеление — колонна огня по одной цели |
| Лёд ×3 | Ледяная тюрьма — заморозка всех вокруг |
| Шторм ×3 | Гнев небес — цепная молния на 4+ переходов |
| Пламя ×2 + Лёд | Расплав — лужа, жжёт и снимает броню |
| Пламя ×2 + Шторм | Хаос-метеор — катящийся метеор с поджогом |
| Пламя + Лёд + Шторм | Оглушающий взрыв — конус с отбрасыванием и оглушением |
| Пламя + Лёд ×2 | Стена льда — режет и замедляет на 60% |
| Пламя + Шторм ×2 | Ускорение — скорость атаки и удары молнией |
| Лёд ×2 + Шторм | Морозный шаг — невидимость, скорость и лечение |
| Лёд + Шторм ×2 | Смерч — подбрасывает всех на линии |

Таблица всех связок доступна прямо в игре — на экране героя и в панели умений.
Автобой умеет подбирать связку под ситуацию: замораживает толпу, уходит
Морозным шагом при низком здоровье, бьёт Испепелением по боссам.

## Предметы (30)

Четыре редкости: обычные, редкие, эпические, легендарные — цвет рамки в лавке.
Инвентарь на 6 слотов. **Любой предмет продаётся обратно за 60% цены** — нажмите
на него в инвентаре, появится кнопка продажи. Предметы действуют только внутри забега.

Кнопка **АВТОЗАКУП** подбирает предметы под главный атрибут героя и тратит всё золото.

## Враги (10 типов + 4 босса)

Враги нарисованы отдельным визуальным языком: у героев круглые тела с оружием,
у врагов — угловатые тёмные силуэты с рваными шипами и светящимися глазами-щелями.
Спутать их невозможно даже в толпе.

| Враг | С волны | Особенность |
|---|---|---|
| Порождение | 1 | базовый ближний бой |
| Костеплюй | 1 | стреляет издалека |
| Тенегон | 3 | очень быстрый |
| Костолом | 4 | много здоровья и брони |
| Скверноус | 5 | магический урон |
| Гнойник | 6 | взрывается вплотную и после смерти |
| Гнилодух | 7 | лечит союзников, держится позади |
| Панцирник | 8 | 12 брони, медленный |
| Гнус | 9 | нападает роем по 4 |
| Проклятая | 11 | замедляет ударами |

### Боссы

**Босс приходит каждую десятую волну**, всего их десять — после десятого начинают
повторяться. У каждого свой силуэт, своя идея боя и три-четыре умения с раздельными
перезарядками. На пороге здоровья босс входит во вторую фазу: перезарядки на треть
короче, урон выше, силуэт светится. Площадные атаки предупреждают пунктирным
кругом — из него надо выйти. В момент появления показывается плашка с именем и
замыслом, сверху висит полоса здоровья.

| Волна | Босс | Замысел | Умения |
|---|---|---|---|
| 10 | Костяной Владыка | чем дольше бой, тем больше костяков | круговой удар · веер копий · поднимает мертвецов |
| 20 | Пожиратель Бездны | наказывает и за близость, и за побег | крюк · кусает и лечится от урона · лужи бездны |

Прислужники боссов (костяки, отражения, личинки) — team 1, так что волна не
кончится, пока их не добьют. Описания и наборы умений в `js/content/enemies.js`,
реализация в объекте `BOSS` в `js/game/ai.js`.

### Смена арены

**После каждого убитого босса игра переезжает на следующую арену** по кругу из
десяти локаций. Ландшафт, фон и погода перестраиваются на лету, снаряды и зоны
со старой арены гасятся, герой встаёт в центр новой. Порядок — `ROTATION`
в `js/content/maps.js`.

## Автобой

Кнопка **АВТО** в HUD или `Пробел`. ИИ:

- бьёт в первую очередь знахарей, потом ведьм, боссов и подрывников;
- держит дистанцию под дальность своего героя, отходит на максимум при низком здоровье;
- уходит из телеграфов боссов и не подпускает к себе подрывников;
- не залипает в углах арены;
- применяет умения по ситуации, а не по кулдауну: площадные — когда рядом 2+ врага,
  спасательные — когда мало здоровья или окружили, добивающие — когда есть раненая цель;
- между волнами сам распределяет очки умений и закупается.

## Управление

**Основное на компьютере — правая кнопка мыши, как в Dota.** Клик по земле отправляет
героя в точку, клик по врагу — подойти на дистанцию атаки и бить его. Удержание ведёт
героя за курсором, `H` — стоп. Любое нажатие `WASD` перехватывает управление и
отменяет приказ.

- Умения `1` `2` `3` (дубли `Q` `E` `R`), вызов связки Аркана `4` или `F`
- Автобой `Пробел`, пауза `Esc`
- **Телефон:** джойстик слева, кнопки умений в нижней панели

## Интерфейс

HUD собран по образцу Dota: снизу по центру одна панель — портрет героя с уровнем
в кружке, полосы здоровья, маны и опыта, ряд умений, а справа золото и сетка предметов
3×2. Сверху остаются номер волны, название арены и полоса здоровья босса.
Связка реагентов Аркана встроена в ту же панель над умениями.

## Таланты

На **10, 20, 30, 40 и 50 уровнях** герой выбирает один талант из двух — окно
всплывает сразу, пропустить нельзя. У каждого героя своё дерево из десяти талантов.

Часть просто добавляет характеристики, часть меняет работу умений: у Мясника крюк
начинает оглушать или тянуть всех на линии, Гниль перестаёт есть его здоровье;
у Егеря залп стреляет во все стороны, а Пронзающая стрела дробится; у Берсерка
Безумие не снимает броню, а «Второе дыхание» один раз за забег отменяет смерть;
у Хладны урон по замороженным удваивается; у Голема четверть полученного урона
возвращается атакующему; у Аркана связка из трёх одинаковых стихий бьёт на 60%
сильнее, а каждая третья срабатывает дважды.

Выбранное видно в панели умений. Когда все умения упёрлись в потолок, лишние
очки уходят в главный атрибут по +3 за очко.

Дерево — `js/content/talents.js`, применение — `js/game/talents.js`.

## Облики, Осколок Аганима и имморталки

У каждого героя **три облика**:

- **базовый** — бесплатный и намеренно скромный, приглушённая палитра без эффектов;
- **редкий** — покупается за души, яркая палитра;
- **имморталка** — открывается за просмотр рекламы: полный сет со своей палитрой,
  аурой под ногами и **собственным эффектом в бою**.

Эффект имморталки срабатывает на попадание, на убийство и на применение умения:

| Эффект | В бою |
|---|---|
| Шлейф | росчерк по цели, кольцо на добивании, вихрь при касте |
| Искры | угольки от каждого удара, тело вспыхивает при смерти |
| Мороз | иней осыпается с цели, при добивании она рассыпается льдом |
| Руны | руна вспыхивает на цели, столб света на убийстве |
| Гроза | разряд перескакивает с цели на ближайшего соседа |

Урона эффекты не добавляют — только визуал, баланс не трогают.
Собраны в `js/game/skinfx.js`, палитры — в `js/content/skins.js`.

**Осколок Аганима** — легендарный предмет в лавке (5200 золота). Кроме характеристик
усиливает ключевое умение героя: крюк Мясника пробивает и тянет всех на линии,
Пронзающая стрела Егеря дробится на попадании, Морозная нова бьёт дважды,
Каменный кулак метает две глыбы, у Аркана растёт сила всех связок.

Облики — `js/content/skins.js`, предмет — в конце списка `js/content/items.js`.

## Сюжет

После каждого убитого босса открывается **глава комикса** — своя у каждого из десяти
героев, по пять глав на героя. Панели рисуются процедурно: палитра под настроение
сцены, косые лучи, силуэт героя. Мясник разбирается с собственным заказчиком,
Егерь идёт по следу сожжённой деревни, Хладна отпускает лёд, под которым
осталась деревня, Аркан ищет четвёртую стихию и находит себя.

Прочитанные главы сохраняются. Тексты — `js/content/story.js`, отрисовка — `js/ui/comic.js`.

## Настройки

Отдельный экран из меню и из паузы: звук, тряска экрана, числа урона,
сброс прогресса с подтверждением.

Там же **переключатель режима**. Отладка включается сама, когда SDK не загрузился
(запуск с диска), но её можно выключить и играть локально по честным правилам —
души и золото начнут копиться как на Яндексе. На Яндексе переключатель скрыт,
потому что отладка там не включается.

## Руны

Каждые 32 секунды на свободном участке арены загорается руна. Подбирается
наступанием, одновременно на поле лежит не больше двух, непобранная тускнеет
через 26 секунд. Автобой делает крюк за руной, если она в пределах 520 и
герою ничего не угрожает.

| Руна | Что даёт |
|---|---|
| Двойной урон | урон атаки х2 на 25 сек |
| Ускорение | +45% скорости передвижения и атаки на 20 сек |
| Регенерация | быстрое восстановление здоровья и маны, 14 сек |
| Невидимость | враги теряют вас из виду, 18 сек |
| Аркана | −40% к перезарядке, мана не кончается, 22 сек |
| Богатство | мгновенно даёт золото по номеру волны |

Набор и настройки спавна — `js/content/runes.js`, логика — `js/game/runes.js`.

## Визуал и анимации

- **Герои — фигуры, а не кружки.** Каждый собирается из ног с походкой, торса
  (латы, роба, кожа, мех, камень, мясницкий фартук), наплечников, плаща, головы
  с лицом и оружия в руке. Корпус всегда стоит прямо и зеркалится по направлению
  взгляда, поворачивается только рука с оружием — поэтому броня и лицо читаются
  под любым углом, а не превращаются в вертящийся диск.
  Наборы внешности — таблица `KITS` в `js/render/shapes.js`: цвет кожи, ткани,
  брони и отделки, тип головного убора и оружия. Костюм собран под архетип роли:
  танки закованы в пластины с юбкой доспеха, стрелки носят кожу с перекрёстными
  ремнями и колчан за спиной, маги — длинные робы с накидкой и флаконами на поясе,
  ассасины — капюшон, маска и ножны с запасными клинками.
  Мясник в кожаной маске и залитом кровью фартуке с крюками на поясе, Рыцарь
  в глухом шлеме с гребнем, накидкой с гербом и щитом за спиной, Клинок Тени
  в маске со светящейся полосой, Хладна и Аркан в остроконечных шляпах (у Аркана
  парящий фолиант за плечом), Берсерк в рогатом шлеме с меховым воротником и
  черепами на поясе, Дриада в венке из листьев, Голем сложен из каменных блоков
  со светящимся ядром в груди.
- **Своя анимация у каждого героя.** Таблица `PROFILES` в `js/render/anim.js`
  задаёт амплитуду и частоту покачивания, высоту парения и наклон при беге.
  Замах привязан к оружию: Мясник рубит с оттяжкой, Рыцарь делает выпад,
  Клинок Тени бьёт двойным веером, Берсерк — серией из трёх, стрелки натягивают
  тетиву и откатываются назад, маги парят и не касаются земли.
- **Личные эффекты покоя.** Вокруг Аркана вращаются три реагента (загораются по мере
  набора связки), Пиромант окружён языками пламени и сыплет угольками, Голем вращает
  каменные обломки, Хладна парит в морозном круге, Клинок Тени оставляет шлейф теней
  при беге, Берсерк истекает кровью на низком здоровье.
- **Освещение.** Динамические источники света от героя, снарядов, жаровен, лавы,
  кристаллов и врагов, накладываются в режиме `lighter`.
- **Стоп-кадры.** Короткая заморозка времени на критах, оглушениях, взрывах
  и смерти босса — удары ощущаются весомо.
- **Ближний бой видно от дальнего.** У ближников удар — размашистая дуга, которая
  проходит перед героем: три следа с затуханием, белое остриё на конце, радиус
  совпадает с реальной дальностью атаки. У дальнобойных — вспышка конусом у самого
  оружия, отдача корпуса назад, натянутая тетива в момент выстрела и снаряд со шлейфом.
  Спутать невозможно даже боковым зрением.
- **Прочее:** мягкие тени с учётом высоты прыжка, запечённая процедурная текстура пола,
  шлейфы у снарядов, искры при попаданиях, угольки на фоне, цветокоррекция под карту,
  виньетка, красная кайма при низком здоровье, вспышки экрана.

## Режим локальной отладки

Если `/sdk.js` не загрузился (запуск с диска или локального сервера),
игра включает режим отладки: **все герои открыты, души и золото бесконечны**,
в меню горит красный бейдж «ОТЛАДКА».

На Яндексе SDK загружается всегда, поэтому режим там не включается.
Отвечает за это ветка `.catch()` в `init()` (`js/platform/sdk.js`) — если
хочется убрать совсем, достаточно удалить строку `devMode = true;`.
Весь код, который смотрит на этот флаг, собран в `js/ui/dom.js`.

## Как собрать архив для Консоли

`index.html` должен лежать в корне архива, а не внутри вложенной папки:

```
zip -r arena.zip index.html css js -x "js/_OBSOLETE.md"
```

Перед сборкой удалите файлы, перечисленные в `js/_OBSOLETE.md` — это остатки
монолитной версии, игра их не подключает.

## Про названия и внешний вид героев

Имена и образы оригинальные — узнаваемые архетипы MOBA, а не персонажи Dota 2.

Причина: п. 3.5 требований прямо говорит, что авторские права на все материалы
должны принадлежать создателю. Имена героев Valve — это чужой товарный знак,
а их иконки и модели — чужие изображения. Игра с ними либо не пройдёт модерацию,
либо будет снята с публикации по жалобе правообладателя уже после релиза,
вместе со всей накопленной статистикой и рейтингом.

Если всё же нужно переименовать — правится только поле `name` в массиве `HEROES`
в `js/data.js`, движка это не касается.

## Балансные ручки

Всё собрано в `js/content/attributes.js`:

```js
ATTR             // сколько даёт очко силы, ловкости, интеллекта
MAX_HERO_LV      // предельный уровень героя (50)
BOSS_EVERY       // через сколько волн приходит босс (10)
ATTR_PER_POINT   // сколько атрибута даёт лишнее очко умений
goldPerWave(w)   // золото за волну
xpPerWave(w)     // опыт за волну
xpToLevel(lv)    // опыт до следующего уровня
soulsFor(w, k)   // души в конце забега
enemyScale(w)    // множитель здоровья и урона врагов
enemyCount(w)    // размер волны
skillCap(lv)     // потолок уровня умения
upgradeCost(lv)  // цена постоянного уровня героя
SELL_RATE        // доля цены при продаже предмета
```

Выбор типа моба по волне — `roll()` в `js/content/enemies.js`
(поля `from` и `weight` у каждого врага).
